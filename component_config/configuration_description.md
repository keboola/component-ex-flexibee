### Connection

Set the **Base URL** (e.g. `https://your-host.flexibee.eu`), **Company** (firma identifier), **Username** and **Password**. Use **Test connection** to verify access.

### Evidence rows

Add one row per evidence type to extract. Pick the **Evidence type** from the list, and optionally set a **Date from / Date to** window on `lastUpdate` (relative like `5 days ago` or absolute `2026-01-01`) to load incrementally. Leave the window empty for a full load. Choose the **Detail level** (`full`, `summary`, or `custom` with a field list) and an optional advanced WQL **filter**.
